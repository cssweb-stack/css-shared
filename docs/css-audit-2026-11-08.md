# Shared CSS review — November 8, 2026

Reviewed all 18 authored top-level files in `src/css`, their shared import order,
and the SSRI, Geography and style-guide consumers. The captured UH reference CSS
in `_uh-reference` was excluded: it is reference material, not published CSS.

## Result

The accepted SSRI design is preserved. Duplicate rules and obsolete variable
references were cleaned up without replacing the shared layout architecture.
All three builds and the shared checks pass. Local Chrome checked 66 built pages
at 375, 576, 768, 992, 1200 and 1440px: 396 cases and 170,628 element snapshots.
There was no page-level horizontal overflow before or after cleanup.

SSRI has no measured geometry or normal-state computed-style changes from this
cleanup. The expected geometry changes are on nine Geography profile pages:
publication images now receive their intended 1px border, slightly affecting
image height. Repaired profile/news text and border colors are also expected.
The summary is in `exports/css-audit-2026-11-08.json`.

## Changes made

- Removed the exact duplicate declaration-spacing rule in `special-text.css`.
- Combined the split hero-image rule in `hero.css`.
- Consolidated identical child-sizing rules for existing shared custom grids.
- Consolidated profile-card properties and repeated profile typography selectors;
  removed redundant paragraph margin resets.

  fallbacks and variables supplied by shared templates/data remain supported.
  A missing-token fixture confirmed the check fails as intended.
- Corrected stale footer/sidebar/layout/diagnostic documentation.

## Current layout contract

- Bootstrap owns primary row/column layout. Rows use `gx-0 gx-sm-5 gx-lg-5`.
- `.container` owns horizontal geometry, with usable content capped at 87.5rem.
  Its side gutter has a 2rem minimum from 576px to contain Bootstrap's outward
  1.5rem row gutter. Below 576px, the original 1rem/4vw minimum is retained.
- Exactly one `.site-main` controls page-edge padding: 3rem above and below at
  every width. Gray sections use the same content-spacing value internally.
- Footer section padding remains responsive through `--layout-section-spacing`:
  2rem phone, 2.25rem tablet, 3rem from 1200px. Desktop language-row separation
  uses that token. This is separate from the constant page-content padding.
- Stacked sidebar/footer groups use the shared 1.5rem gap, omitted when the
  groups sit side by side on tablet.
- Directory names, emails and phone numbers stay on one line on desktop;
  descriptive fields may wrap. Contact cells align to the top of tall rows.
- Body paragraphs remain 1.125rem; H1 sizes are 2rem/1.875rem/1.75rem.
  The unit title uses a bounded 1.5–2rem size and may wrap.

## Retained deliberately and review limits

Existing custom grids remain because Geography, shared components and specimens
use them. Migrating them to Bootstrap is separate work, requiring visual review;
unused-looking public classes were not deleted speculatively.

Diagnostics remain ON for the requested header proofreading. Disable the final
import in `common.css` and rebuild before publishing the normal presentation.
Jack's profile is still a content placeholder; this audit does not finish it.

The browser comparison uses static built HTML, real Inter fonts and local images.
Site JavaScript, live feeds and external map content were excluded to isolate CSS;
this is not an end-to-end interaction test. Earlier header/menu checks are separate.
Actual iPad/iPhone Safari checks, zoom/focus review and real content review remain
necessary before treating the site as launch-approved. Fixed footer acronym sizes
also remain an explicit design choice; the earlier footer-only review records
fit limits for longer unit abbreviations near narrow breakpoints.
