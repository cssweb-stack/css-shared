# UH stylesheet reference

`styles.css` was supplied by the user on November 8, 2026 as the intended UH
comparison stylesheet. Preserve it unchanged. It is a reference snapshot, not
an import into `common.css` or a replacement for our shared styles. Builds only
bundle imported styles, and passthrough copying does not publish this directory.
The shared checker excludes captured CSS here from our authored-CSS line-height
and asset rules, since external snapshots have their own dependencies/conventions.

This reference differs from the older UH WordPress Total-theme snapshots under
`docs/references/uh-manoa/`. Those older files are not the intended baseline.
